# LapanganKu

The active LapanganKu website is the Laravel app in [`laravel/`](./laravel/). Start it from the repository root with:

```sh
cd laravel
php artisan serve
```

Open `http://127.0.0.1:8000`. Setup, database, and feature details are in [`laravel/README.md`](./laravel/README.md).

The original root-level PHP pages and JSON data are retained as a backup/reference. Use the Laravel server for the unified website.
